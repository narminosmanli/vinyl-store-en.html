# Skull & Needle — Vinyl Records (HTML Practice Project)

This is a hands-on practice project built around a retro vinyl record shop theme,
bringing together the core HTML topics: semantics, text formatting, links, lists,
tables, forms, and `div`/`class`/`id`.

## Files

- `vinil-magaza.html` — Azerbaijani version
- `vinyl-store-en.html` — English version

## Topics used on the page

- Document structure and semantic tags: `<header>`, `<nav>`, `<section>`, `<footer>`
- Text formatting: `<strong>`, `<em>`, `<blockquote>`, `<cite>`
- Links: `<a href="...">`, including `mailto:`
- Lists: ordered (`<ol>`), description list (`<dl>`, `<dt>`, `<dd>`)
- `<address>` — semantic tag for contact/location info
- `<div>` with `class`/`id` for grouping and styling
- Table: `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
- Form: `<form>`, `<input>` (text, email, radio), `<select>`, `<textarea>`, `<button>`
- `<details>` / `<summary>` — collapsible FAQ section
- Inline CSS (`<style>`) with a vintage design and a spinning vinyl animation

## How to open

1. Open the file for your preferred language in VS Code.
2. Click "Go Live" (Live Server extension) — the page opens automatically in your browser.
3. Alternative: double-click the file to open it directly in your default browser.

## Purpose

This project was built to practice applying various HTML tags on a real-feeling
subject. The theme (a vinyl record shop) is fictional and was chosen purely for
practice purposes.
